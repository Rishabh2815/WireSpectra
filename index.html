WIRESPECTRA
C++ · PCAP analysis

See what’s inside your traffic.

WireSpectra is a deep packet inspection engine for analyzing packet captures, classifying application traffic, and applying configurable filtering rules.

View source on GitHub Build and run

Application signatures

Classify known services from TLS SNI and HTTP host information in captured traffic.

QUIC and HTTP/3

Identify UDP port 443 traffic and inspect supported QUIC Initial ClientHello data.

Traffic rules

Filter by application, domain, or source IP, with rules loaded from a local file.

Capture statistics

Review packet counts, classifications, forwarding, and throttling while processing PCAP files.

Deployment note: This website is a static project page. The C++ analyzer processes saved PCAP files and must run separately on a host with the required build tools and capture files.
